# Project instructions

Use uv for all Python work and an isolated virtual environment. On this host keep environments and caches on D:.

Use the chain-of-evidence workflow for mathematical claims, research, experiments, benchmarks, and audits. Preserve typed source/assumption/implementation provenance and raw evaluator artifacts. Never infer novelty or open-problem status from a corpus gap. Keep known results, conjectural connections, modelling assumptions, and verified computations visibly distinct.

Keep shared writes serial. Independent read-only investigation is encouraged; implementation cannot self-certify the final evidence gate. The Site owner alone edits/deploys the website. Commit meaningful changes and retain reproducible commands.

The enduring goal is broader than any release. Do not mark mapping all mathematics complete because a bounded corpus or test suite passes.
