# Source-target evidence guide

Contract: docs/kemeny-source-target-contract.md.
Bundle: .codex/evidence/runs/kemeny-source-target-v1/bundle.json.

- theorem/ and theorem-review/: directed first-step formula, coercivity,
  quasiconvexity and candidate characterization with a distinct audit. The
  review's initial missing-SymPy launcher and authorized recovery are retained.
- boundary/ and boundary-review/: fixed-source nonattainment with first-step
  equations and a distinct analytic audit, no claimed fresh reviewer evaluator.
- implementation/ and implementation-review/: portable code, frozen pins,
  worker result, byte-identical fresh replay and overwrite rejection/raw logs.
- integration/: the one root canonical output, raw log and exact comparison.
- sources/model/ and model-review/: bounded primary literature/repository
  assessment and distinct source audit.
- sources/objective/ and objective-review/: immutable author-code normalization,
  damping and intervention alignment, with distinct static audit.
- sources/discovery/ and raw-retention.json: original request metadata and
  full-return hashes. Third-party full text/code remains local. The source notes
  have exact primary URLs/locators; no bulk source redistribution is included.
- final-review/: final four-check audit, added after the frozen input is reviewed.

copy-manifest.json records byte-preserving copies. Historical source-stage paths
are provenance, not portable runtime dependencies. Worker-stage statements about
pending approval are retained historical records; they do not substitute for
the separate final gate. Local release approval does not imply hosted CI success.
