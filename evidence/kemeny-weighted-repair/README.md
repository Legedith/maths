# Weighted repair and strength evidence

The [theorem](../../docs/kemeny-weighted-repair.md),
[frozen contract](../../docs/kemeny-weighted-repair-contract.md), and
[typed bundle](../../.codex/evidence/runs/kemeny-weighted-repair-v1/bundle.json)
define this release. It covers every prescribed positive conductance,
then the joint optimum over location and strength with no monetary penalty.

`weight-author` and `strength-author` preserve the frozen hypotheses and
proof packets. `weight-review` and `strength-review` contain independent
mathematical derivations and exact checks. The first weight-review batch
was stopped for excessive expression expansion; the second simplified the
same differences before substitution and passed. Both remain retained.

`implementation` contains the new portable worker packet. Its first attempt
produced matching output but the exit-code capture was empty, so that exit
status remains unknown. Canonical attempt2 has recorded rc0. The separate
`portable-review` packet contains an independent fresh replay and rejection
of a modified certificate. `integration` records the repository command.
Original scripts retain their actual stage paths; the dependency-free
repository checker is the fresh-checkout route.

The checker verifies nine complete rational identities and clearly marked
finite diagnostics. The generic calculus, graph-to-walk reduction, endpoint
arguments and global quantifiers have explicit separate proof audits.
[Source notes](source/README.md) distinguish published machinery, inferred
normalization and the specific family result. Bulk papers and raw web
returns stay outside public Git; hashes and concise reviews are retained.

`copy-manifest.json` pins copied bytes. The separately appended final review
covers final prose, typed claims and integration; the configured workflow
retains raw outputs. Actual CI is inspected after push. Earlier bundles
remain tied to their historical release revisions, including the unit
release at 286aff954c0369f1cdff9680c75cfd5724f0b2af.

The later classification of optimal strength relative to one is excluded.
No global originality, measured network benefit or Lean formalization is
certified by this package.
