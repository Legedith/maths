# Incremental alternative-repair evidence

[The theorem and uv command](../../docs/kemeny-alternative-repair.md)
complete the optimal edge set when restoration is forbidden. The
[frozen contract](../../docs/kemeny-alternative-repair-contract.md) and
[current bundle](../../.codex/evidence/runs/kemeny-alternative-repair-v1/bundle.json)
define this incremental release.

`author` retains the candidate, one declared batch, input hash and complete
coefficient lists. `math-review` retains the independent exact comparison
audit and reused full-matrix witness. `portable-review` records the changed
implementation review, fresh replay and rejected modified input.
`integration` holds root's canonical result and raw command streams.
[copy-manifest.json](copy-manifest.json) pins the public copies.

The prior graph-to-quotient proofs, singleton arithmetic, uv domination,
certificates and audits remain unchanged in the previous package. This
bundle pins only the exact reused files needed by this theorem, plus the
new evidence. Full prior deterministic checks need not be repeated to
verify unchanged dependencies.

Historical bundles apply to their recorded release revisions. In
particular, the preceding single-failure bundle passed at commit
addc03ed0f4b4eff84e5d065d868b3fbcd9e5944. Its original bytes remain retained;
the current bundle covers documentation changed by this addition. Check
historical bundles against their corresponding Git revision.

Historical author/reviewer scripts keep their actual stage paths and uv
environments. The dependency-free repository checker is the fresh-checkout
route. The workflow is configured to execute it and retain raw results;
actual CI is inspected after push. No full third-party paper or local
environment is included in public Git.

The fixed-workload investigation is separate. This certificate proves
stationary-target K optimality, not deployed benefit or an optimum for a
fixed destination distribution. Global originality remains unestablished.
