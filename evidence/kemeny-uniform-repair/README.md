# Fixed-uniform repair evidence

The [theorem](../../docs/kemeny-uniform-repair.md) gives the exact minimizing
insertion set and proves it strictly improves over no insertion under a
fixed uniform workload. The [contract](../../docs/kemeny-uniform-repair-contract.md)
and [typed bundle](../../.codex/evidence/runs/kemeny-uniform-repair-v1/bundle.json)
define this release.

`ranking-author` and `noop-author` preserve separate frozen ideas, bounded
tests and complete coefficient lists. `ranking-review` and `noop-review`
retain independent graph-equation derivations and exact identities.
`portable-review` preserves fresh reproduction, the original mistaken
negative-test invocation, its correction, and the rejected modified input.
`integration` records the canonical repository command. The dependency-free
checker is the fresh-checkout route; original research scripts retain
their actual stage paths and isolated uv environments.

`source` contains concise independently checked primary-source notes and
review, with explicit attribution of generic methods and access gaps.
Bulk third-party papers and raw web returns stay outside public Git.
`copy-manifest.json` pins copied bytes; a separately appended final-review
packet covers final prose, claims and integration. The configured workflow
retains results and raw command streams; actual CI is checked after push.

Older bundles describe their recorded release commits, including the
alternate-repair bundle at d73319ed93131495036442b1b32b902eee18708f.
Their original bytes are retained. This bundle pins reused unchanged
arithmetic and covers the newly changed documentation and workflow.

The later all-positive-weight ranking candidate is excluded. No practical
performance, nonuniform workload or global publication priority claim is
certified here. The weighted threshold example has an open improving
interval; its endpoint gives equality, as the independent review explains.
