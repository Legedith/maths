# Discovery extension: frozen contract, 2026-09-08

The user added a stopping condition: obtain a new discovery, algorithm, optimization, or concept, verified in Lean 4 or algorithmically proved and independently audited. The full mathematics map remains an expanding objective. A finite atlas is not full coverage, and an implementation of a known identity is not new mathematics.

Explore three independent directions grounded in the current Laplacian atlas and exact graph engine. Each branch must distinguish prior art, proposed contribution, testable statement, assumptions, proof obligation, falsification method, and scope of novelty. Prefer a useful original optimization of the project's actual workload, or a precise mathematical conjecture with a tractable full proof. A finite experiment can prove an explicitly bounded statement; it cannot establish an unrestricted theorem. Global novelty needs a documented prior-art search and still warrants calibrated wording.

Evaluation is fixed before selecting a candidate: use exact arithmetic; reproduce all existing frozen engine fixtures; compare to an independent algorithm on every labelled connected simple graph on 2..5 vertices, with named 6-vertex boundary cases. Any broader claim needs an algebraic/combinatorial proof or proof certificate valid for its complete stated domain. Optimization must preserve every relevant output and reject unsupported input. Compare operation counts where possible and wall time over repeated deterministic runs with identical inputs, environment, warm-up and reporting. Do not change the workload or silently omit expensive outputs to claim speedup. Keep canonical baseline available, raw failures, outputs and proof details. Do not tune on a held-out benchmark and call it independent. State whether complexity is arithmetic-operation or bit complexity.

Root owns specification, selection, integration and claims. Parallel Sol Max agents explore independently and read-only; root keeps shared writes serial. A separate agent that did not author the result must inspect the proof, code and raw artifacts and rerun canonical checks. Neither author nor implementer can certify final success. Literature discovery, interface work and finite verification are useful progress, but do not by themselves satisfy the new stopping condition.
